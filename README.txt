DexifyBlast APK kit

1. Make a new GitHub repo and upload everything inside this folder.
2. Check the repo shows a ".github" folder. If not, on github.com use
   Add file > Create new file, type  .github/workflows/build-apk.yml  as the name,
   paste in the contents of workflow-copy.txt, and commit.
3. Open the Actions tab. "Build APK" runs automatically (or press Run workflow).
4. After about 5 minutes open the run, download "DexifyBlast-apk" under Artifacts,
   unzip it, and install app-debug.apk on your Android phone.

workflow-copy.txt is only a copy to paste from. GitHub does not read it.
